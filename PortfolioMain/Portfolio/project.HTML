01

SEA RESCUE WATERSORTER

รายละเอียด: เป็นการสร้างถังขยะอัจฉริยะที่ทำงานร่วมกับวิดีโอเกม เมื่อผู้เล่นทิ้งขยะลงในถังขยะจริง เซนเซอร์จะตรวจจับและสุ่มสร้างขยะขึ้นมาในหน้าจอเกมใต้ทะเล ซึ่งผู้เล่นจะต้องบังคับสัตว์ทะเลเพื่อเก็บและแยกขยะให้ถูกต้องตามประเภทถังสีต่างๆ ภายใต้เวลาที่กำหนด

  • ด้านฮาร์ดแวร์: ใช้บอร์ดไมโครคอนโทรลเลอร์ NodeMCU ESP8266 ทำงานร่วมกับเซนเซอร์ Ultrasonic (HC-SR04) เพื่อตรวจจับระยะการทิ้งขยะ
  • ด้านซอฟต์แวร์: ใช้โปรแกรม Processing ในการสร้างภาพและควบคุมระบบของเกมทั้งหมด และใช้ระบบ Arduino ในการส่งสัญญาณจากเซนเซอร์ไปยังคอมพิวเตอร์
  • เป้าหมาย: เพื่อแก้ไขปัญหาการทิ้งขยะไม่เป็นที่และลดผลกระทบจากไมโครพลาสติกต่อสัตว์ทะเล โดยเปลี่ยนการเรียนรู้เรื่องการแยกขยะที่น่าเบื่อให้กลายเป็นความสนุก เพื่อช่วยสร้างความตระหนักรู้และจิตสำนึกในการรักษ์โลกให้กับผู้เล่น
02

Smart Greenhouse

รายละเอียด: เพื่อจำลองการทำงานของระบบเครือข่าย IoT ทางการเกษตร โดยมุ่งเน้นแสดงให้เห็นถึงการรับส่งข้อมูลเซนเซอร์ การประมวลผลตามเงื่อนไข และการควบคุมอุปกรณ์ฮาร์ดแวร์แบบอัตโนมัติที่ถูกต้องและปลอดภัย เพื่อนำไปประยุกต์ใช้กับโรงเรือนปลูกพืชในชีวิตจริง

Core Features & Architecture

  • ระบบควบคุมอัตโนมัติ (Rule-based Automation): มีการประมวลผลสภาพอากาศ หากอุณหภูมิสูงกว่า 30°C ระบบจะสั่งเปิดพัดลมระบายอากาศ และหากความชื้นในดินต่ำกว่า 40% ระบบจะสั่งเปิดปั๊มน้ำ
  • ระบบจัดการคิว (Queue Management): มีตัวล็อก (Lock) ป้องกันไม่ให้ส่งคำสั่งชนกัน หากมีการสั่งงานอุปกรณ์ตัวแรกอยู่ ระบบจะรอจนกว่าจะสำเร็จแล้วจึงขยับไปสั่งอุปกรณ์คิวถัดไป
  • ระบบทดสอบแยกอิสระ (Manual Override): แยกระบบออโต้และการกดปุ่มสั่งการเอง (Device Test) ออกจากกันชัดเจน ทำให้ผู้ใช้ควบคุมระบบด้วยมือได้โดยที่กฎอัตโนมัติไม่เข้ามาแทรกแซง
  • การจัดการข้อผิดพลาด (Failure Handling): ระบบถูกออกแบบมาให้ทนทานต่อข้อมูลขยะ หากเซนเซอร์ส่งข้อมูลมาไม่ครบ (Validation Failed) หรือไฟล์ JSON เสียหาย (Syntax Error) โปรแกรมจะไม่ค้าง แต่จะแจ้งเตือนและกลับไปใช้ข้อมูลที่เชื่อถือได้ล่าสุด (Last Trusted Data)

    Technologies & Architecture

    • Unity 3D และ C# (Core Engine): ใช้เป็นแกนหลักในการพัฒนา ทั้งการเขียนลอจิกประมวลผล, การจัดการหน้าจอ UI, และการแสดงผลโมเดล 3D ให้ขยับตามสถานะจริง (เช่น ใบพัดลมหมุน และเอฟเฟกต์พ่นน้ำ)
    • JSON: ใช้เป็นรูปแบบมาตรฐานกลางในการแลกเปลี่ยนข้อมูลทั้งหมด ทั้งการรับค่าเซนเซอร์ (Input), การส่งคำสั่งควบคุม (Command), และการรับข้อความตอบกลับ (ACK)
    • IoT State Management: ประยุกต์ใช้แนวคิดระบบคลาวด์ IoT ของจริงอย่างสมบูรณ์แบบ โดยเริ่มจากการส่งคำสั่งไปตั้งค่า (Desired State) จำลองความหน่วงของเครือข่าย 2 วินาทีจากนั้นต้องรอให้อุปกรณ์ตอบรับยืนยัน (ACK) ก่อน ระบบจึงจะอัปเดตโมเดล 3D ให้ตรงกับความเป็นจริง (Reported State)

เป้าหมายเพื่ออะไร

  • เพื่อจำลองและทดสอบระบบควบคุม IoT อัตโนมัติ โดยระบบจะวิเคราะห์ค่า อุณหภูมิและความชื้น เพื่อสั่งเปิด-ปิด พัดลมระบายอากาศและปั๊มน้ำ อย่างเป็นระบบ (มีระบบคิวป้องกันคำสั่งทำงานชนกัน) ช่วยให้เห็นภาพรวมการทำงานของฮาร์ดแวร์ก่อนนำไปสร้างจริง
